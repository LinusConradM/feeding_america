Platform Architecture

From raw data to causal inference — a fully integrated analytics engine

Autonomous Agentic Reasoning

The platform is augmented by Gemini 2.5 Flash with a secure Python code execution sandbox. It doesn't guess — it writes, tests, and executes Pandas queries directly against the live longitudinal dataframe to mathematically solve plain-English inquiries.

user> What is the DiD policy effect SE in Texas?
agent> Extracting regression coefficients...
agent> Standard error: ±0.042 percentage points
Causal Inference Engine

Pivots from descriptive to prescriptive analytics. Uses Difference-in-Differences modeling to isolate the true causal effect of hypothetical policy shocks against controlled baseline groups — proving impact rather than correlation.

DiD Estimator
β̂ = (Ȳ₁ᵀ − Ȳ₁ᶜ) − (Ȳ₀ᵀ − Ȳ₀ᶜ)
Spatially-Weighted Clustering

K-Means augmented with GPS coordinates to force geographic contiguity. Tracks regional flow shifts using Sankey matrices.

Time Series Forecasting

SARIMAX modeling for temporal trend analysis, pre/post COVID impact assessment, and county-level food insecurity forecasts.

Unsupervised Outlier Detection

Isolation Forests autonomously scan all 3,142 counties to flag severe multivariate anomalies hidden within the economic matrix.

Statistical Methods

A rigorous, multi-method analytical framework

Correlation Testing
Pearson, Spearman, and Kendall τ coefficients for bivariate relationship identification across all socioeconomic variables.
SciPy · statsmodels
Regularized Regression
OLS, Ridge, LASSO, and Elastic Net models with cross-validated hyperparameter tuning and full diagnostic plots.
scikit-learn · statsmodels
Random Forest
Non-linear ensemble model capturing interaction effects and non-monotonic relationships, with feature importance ranking.
scikit-learn
K-Means + PCA
Spatial K-Means clustering augmented with GPS coordinates. PCA projection for 2D visualization, silhouette scoring.
scikit-learn
SARIMAX Forecasting
Seasonal ARIMA with exogenous regressors for temporal trend decomposition and multi-step food insecurity forecasting.
statsmodels
Isolation Forest
Unsupervised anomaly detection isolating county-level multivariate outliers across socioeconomic and food insecurity indicators.
scikit-learn
